📞 Llamadas de WhatsApp desde la web

Baileys Caller

Sistema profesional de llamadas de WhatsApp con panel web moderno, autenticación por QR o código de 8 dígitos, y texto a voz (TTS) en español e inglés.

Ver en GitHub Instalar ahora

Características principales

Todo lo que necesitas para gestionar llamadas de WhatsApp desde tu navegador

🔐

Autenticación dual

Conecta WhatsApp mediante código QR o código de vinculación de 8 dígitos. Ambos métodos usan autenticación real de Baileys.

📞

Llamadas salientes

Realiza llamadas de voz individuales, detecta cuando suena, cuando contestan y cuándo finaliza.

🔊

Audio y TTS

Reproduce archivos MP3, WAV o texto a voz en español e inglés durante las llamadas.

💾

Persistencia

Las sesiones se guardan en disco y se recuperan automáticamente tras reiniciar el servidor.

Métodos de conexión

Elige la forma que mejor se adapte a tu flujo de trabajo

📱

Código QR

Genera un código QR real de WhatsApp que puedes escanear desde la app móvil en Dispositivos vinculados.

1
Haz clic en "Generar QR"
2
Escanea con WhatsApp > Ajustes > Dispositivos vinculados
3
El panel detecta la conexión automáticamente
🔢

Código de 8 dígitos

Introduce tu número telefónico y genera un código de vinculación de 8 dígitos para emparejar el dispositivo.

1
Introduce tu número con código de país
2
Solicita el código de 8 dígitos
3
Ingresa el código en WhatsApp para completar la vinculación

Sistema de llamadas

Control completo de llamadas de voz desde el panel web

📞

Llamar

Introduce el número de destino y haz clic en LLAMAR para iniciar una llamada saliente.

📴

Colgar

Termina la llamada activa en cualquier momento con un solo clic.

⏱️

Control de duración

Configura tiempo máximo de llamada y recibe notificaciones cuando finaliza.

📊

Historial

Registro completo de todas las llamadas con estado, duración y motivo de finalización.

Texto a voz (TTS)

Reproduce mensajes de voz durante las llamadas sin servicios externos

Voces disponibles

Genera audio localmente con espeak-ng. No dependes de APIs externas ni de pago por uso.

Instalación rápida

Pon en marcha Baileys Caller en minutos

🚀 Primeros pasos

git clone https://github.com/abrahamhr2009/baileys-caller.git
cd baileys-caller
npm install
npm run build
npm start
Node.js ≥ 20 FFmpeg espeak-ng WhatsApp activo
